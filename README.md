Deal Drop is a static Black Friday and Cyber Monday deal finder with 39 real deals, each price-checked by an agent on 27 November 2026, searchable and filterable by category, store and discount, with a verdict on whether each deal is really a deal.

## Run it

```sh
python3 -m http.server 8123 --directory app
# open http://localhost:8123/
```

Or build the hand-in the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
